# Infinite Workspace

A Vite + React + TypeScript prototype showcasing an infinite, neomorphic canvas with premium interactions.

## Features
- SVG-based infinite workspace with laid-paper texture and grid overlay.
- Top toolbar for selection, shape creation, connectors, mind-map branches, and quick styling.
- Left burger flyout for file/about/help shortcuts; right flyout for properties and grid/transform controls.
- Basic shapes (rectangle, ellipse, diamond, text) plus hand-drawn tapered connectors with on-path labels and multi-branch mind-map links.
- Smooth pan (right-click drag), wheel zoom, zoom slider, configurable grid spacing, and animated UI polish.

## Getting started
```bash
npm install
npm run dev
```

Open the printed local URL to explore the workspace. Use the tool chips to add elements; right-click drag to pan and the mouse wheel or slider to zoom.
